Trigger rescan

Reconciles the metadata registry against the real photo tree on disk. Runs synchronously on the backend, so this may take a while on a large library — leave the tab open until a result appears below.

Preheat thumbnails

Force-generates thumbnails ahead of time for a portfolio (and its subtree, if recursive) at the given size, so visitors don't wait for on-demand generation.

Cleanup stale thumbnails

Removes cached thumbnail files that no longer correspond to a live image in the registry (e.g. after images were deleted). Reconciles the full cache every time — no parameters needed.

Change photo root

Points the backend at a different base directory and triggers a full reconciling rescan. Existing identity (portfolio/image UUIDs) is preserved. The path must already exist and be a directory on the server the backend container can see — a bad path is rejected before anything changes.
